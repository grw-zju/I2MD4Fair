# I2MD4Fair: Intra- and Inter-Modality Debiasing for Fair Multimodal Recommendation

Official implementation of **I2MD4Fair** (TOIS 2026).

## Overview

I2MD4Fair addresses fairness in multimodal recommendation through two key mechanisms:
- **Intra-Modality Debiasing (Intra-MDM)**: Soft prototype clustering via Sinkhorn optimal transport + hypergraph semantic propagation
- **Inter-Modality Debiasing (Inter-MDM)**: CLUB mutual information estimation (Information Bottleneck) + adaptive p-norm loss

Additionally, InfoNCE cross-modal alignment and BPR recommendation loss are used for training.

## Data Format (DA-MRS)

All datasets use the **DA-MRS format**, stored under `data/damrs/<dataset_name>/`:

| File | Format | Description |
|------|--------|-------------|
| `<name>.inter` | Tab-separated text | Interactions: `userID itemID rating timestamp x_label` (x_label: 0=train, 1=val, 2=test, 8:1:1 random split) |
| `image_feat.npy` | numpy (n_items, 4096) float32 | Visual features (Baby/Clothing: CNN pre-extracted from DA-MRS; MIND: ResNet-50 avgpool 2048-dim) |
| `text_feat.npy` | numpy (n_items, 384) float32 | Textual features (Baby/Clothing: Sentence-Transformer from DA-MRS; MIND: all-MiniLM-L6-v2 384-dim) |
| `image_adj_80.pt` | torch tensor (n_items, n_items) float32 | Top-80 visual similarity adjacency (row-normalized) |
| `text_adj_80.pt` | torch tensor (n_items, n_items) float32 | Top-80 textual similarity adjacency (row-normalized) |
| `u_id_mapping.csv` | CSV | Original user ID → mapped integer ID |
| `i_id_mapping.csv` | CSV | Original item ID → mapped integer ID |

### MIND (From raw data)

MIND requires preprocessing from raw data to DA-MRS format. Steps:

1. **Download raw data** — Place the following in `data/MIND/`:
   - `MINDlarge_train.zip` (from [MIND dataset](https://msnews.github.io/)) — contains `news.tsv` + `behaviors.tsv`
   - `MINDlarge_dev.zip` — contains `news.tsv` + `behaviors.tsv`
   - News images (`N*.jpg`) — from [IM-MIND](https://drive.google.com/file/d/1gx0OzN7qSuyRlvN0cfVUjB4tmoKvvQk1/view), extract to `data/MIND/`

2. **Run preprocessing** (each step can run independently, supports GPU):

```bash
# Step 1: Parse behaviors.tsv → build interactions + 8:1:1 split + ID mappings
python scripts/preprocess_mind.py 1

# Step 2: Extract visual features (ResNet-50 avgpool → 2048-dim, GPU recommended)
python scripts/preprocess_mind.py 2

# Step 3: Extract textual features (SentenceTransformer all-MiniLM-L6-v2 → 384-dim, GPU recommended)
python scripts/preprocess_mind.py 3

# Step 4: Compute top-80 similarity adjacency matrices (memory-intensive for large datasets)
python scripts/preprocess_mind.py 4

# Or run all steps at once:
python scripts/preprocess_mind.py 0
```

Output goes to `data/damrs/mind/` with all files in the DA-MRS format table above.

The current workspace contains processed MIND files under `data/damrs/mind/`.
The local MIND split is `train=13,993,439`, `val=1,749,179`, and `test=1,749,181`.
Use these local counts for experiment reporting.

### Output

Each run prints averaged metrics over `n_runs`:

```text
N@10 N@20 R@10 R@20 G@10 G@20 E@10 E@20 C@10 C@20
```

`N` is NDCG, `R` is Recall, `G` is Gini, `E` is Entropy, and `C` is Coverage.
For fairness, lower Gini and higher Entropy/Coverage are better.

## Model Architecture (Paper Alignment)

The implementation aligns with all equations in the paper:

| Equation | Implementation | Notes |
|----------|---------------|-------|
| Eq 1 | `_modality_message_passing()` with `D_U^{-1}R` and `D_V^{-1}R^T` (asymmetric normalization, sparse) | Separate from LightGCN's symmetric norm |
| Eq 2-3 | `_id_message_passing()` with symmetric normalized Laplacian + layer-wise average | LightGCN-style |
| Eq 4-7 | `SinkhornOT` + `SoftPrototypeClustering` | No epsilon smoothing in Sinkhorn iterations |
| Eq 8 | `update_prototypes()` — weighted mean over current sampled items | Prototypes are buffers, not optimizer-updated parameters |
| Eq 9 | Incidence matrix = cosine similarity (no clamp) | Allows negative entries |
| Eq 10 | `HypergraphConv` with `leaky_relu(0.2)` | σ unspecified in paper |
| Eq 11-14 | `InterMDM` + `CLUBEstimator` | CLUB MI via permutation sampling (standard practice) |
| Eq 15 | Per-modality BPR loss | Modality-specific embeddings |
| Eq 16 | `adaptive_loss()` — p-norm over modality losses | |
| Eq 20 | `InfoNCELoss` — normalize + cross_entropy | Computed over current sampled items to avoid full item-item similarity matrices |
| Eq 21-22 | Concat(X_U, Z_u^k) + Concat(X_V, Z_v^k) + BPR | Z_v^k = post-propagation |
| Eq 23 | Total loss + L2 on all Θ | `_l2_reg()` covers all parameters |

**Training specifics:**
- CLUB parameters excluded from main optimizer (gradient isolation per Eq 13 description)
- CLUB NLL updated on current sampled items per mini-batch (not per epoch)
- Prototype weighted-mean update on current sampled items per mini-batch (Eq 8)
- Xavier initialization on all trainable parameters
- Validation is used for early stopping. Final test evaluation filters both training and validation interactions.

## Evaluation Metrics

**Accuracy (↑):** N@10, N@20 (NDCG), R@10, R@20 (Recall)
**Fairness:** G@10, G@20 (Gini index ↓), E@10, E@20 (Entropy ↑), C@10, C@20 (Coverage ↑)

Gini index uses `1/(|I|-1)` normalization per Eq 24 and includes zero-exposure items in the full item pool.
